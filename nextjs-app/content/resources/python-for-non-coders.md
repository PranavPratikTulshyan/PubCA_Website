# Python for Non-Coders: Where to Actually Start

Most tutorials start with installation. That's not where Python begins.

Python begins with a question: *what do you want to stop doing manually?*

Until you have an answer to that, no amount of `print("Hello, World")` will make it stick.

## The mindset shift

Programming is not memorising syntax. It's translating a process you already understand into a form a computer can follow.

You already know how to describe a process:

1. Open the folder
2. Find files from last month
3. Move them to the archive folder

That *is* Python. Almost word for word.

## Where to actually start

Open [Google Colab](https://colab.research.google.com). No installation. No setup. Just a browser.

Write one line:

```python
print("I am going to automate something today")
```

Run it. That's Python.

Now find one repetitive task in your work. Describe it in plain English. Then we'll translate it together.
